# 灵感构图 · 轻量版

一个纯前端的取景辅助相机：实时画面 + 构图参考线 + 水平仪 + 人脸框选 + 一句构图提示。
不用装 App，用手机浏览器打开就能拍，照片存在手机本地，所有识别都在手机里跑，不联网。

## 里面是什么

```
lumo-lite/
├── index.html                 页面
├── style.css                  样式
├── manifest.webmanifest       PWA 配置（加到主屏幕后像 App 一样全屏）
├── sw.js                      离线缓存
├── icon-192.png / icon-512.png / icon.svg
├── js/
│   ├── app.js                 主逻辑
│   ├── advisor.js             构图建议规则
│   ├── camera.js              摄像头
│   ├── detect.js              人脸检测封装
│   └── overlay.js             参考线 / 引导框 / 水平仪绘制
└── vendor/
    ├── face-api.js            人脸检测库（本地，1.3 MB）
    └── models/                模型权重（人脸检测 190 KB + 关键点 75 KB）
```

## 部署到 GitHub Pages（一次就好）

1. 电脑浏览器打开 https://github.com/new
2. `Repository name` 填 `lumo-lite`，选 **Public**，点 Create repository
3. 在新仓库页面点 **uploading an existing file**
4. 把整个 `lumo-lite` 文件夹拖进浏览器窗口（保留里面的目录结构），等上传完点 **Commit changes**
5. 进仓库的 **Settings → Pages**
6. `Source` 选 **Deploy from a branch**，`Branch` 选 **main**、目录选 **/ (root)**，点 **Save**
7. 等 1~2 分钟，刷新 Settings → Pages，顶部会出现网址：
   `https://你的用户名.github.io/lumo-lite/lumo-lite/`

> 注意最后是两层 `lumo-lite`：因为文件夹本身也在仓库里。
> 如果想让网址短一点（`.../lumo-lite/`），第 4 步改成把文件夹**里面的内容**拖进去，别拖文件夹本身。

## 手机上装到桌面

1. 手机 Chrome 打开上面的网址
2. 第一次会问摄像头权限，点「允许」
3. 右上角菜单 → **添加到主屏幕**
4. 桌面就多一个图标，点开是全屏的，和 App 一样

## 怎么用

- 举着手机对着人：屏幕正中会有一条横线，**把它转平**就说明手机端平了
- 白色的框就是「建议主体待在的位置」，把人挪进框里
- 框里那个**虚线幽灵框**是「脸该放的地方」，橙色的流动箭头会从脸指向它，跟着走就行
- 框变绿 + 提示「构图到位了」，就按快门
- 底部两个小图是两套构图方案：「三分」（人偏右）和「中心」（人居中），点一下切换
- 底部中间的 **人像 / 建筑** 切换场景：
  - **人像**：认脸、画框、给逐字的方向提示
  - **建筑**：看横平竖直（手机歪几度会直接说）、看天空留白比例、「对称」和「三分」两套方案
- 右上角 `⌗` 切换参考线：三分线 → 黄金分割 → 对角线 → 关
- `⟳` 切前后摄像头

## 已知限制

- 拍出来的照片是**取景框里看到的那一块**，分辨率取决于摄像头流（一般 1080p），不是原相机的 5000 万像素
- 没有 OPPO 的哈苏调色、HDR 多帧合成，暗光/逆光会比原相机差
- 第三方网页拿不到长焦镜头，只有主摄
- 人脸检测只认人脸，拍风景/宠物时它只能靠网格和水平仪
- 建议拍完之后丢进相册的「AI 灵感成片」或修图 App 补个滤镜，构图是你现场拿下的，调色后补就行
